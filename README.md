# Evaluating Theory of Mind in Reasoning Models

> _This README was automatically generated by Claude based on the repository's code and structure._

This repository contains the code, prompts, and results for a study evaluating how large language models — particularly "reasoning" models that produce explicit chain-of-thought — perform on Theory of Mind (ToM) tasks. It benchmarks models across classic psychological ToM tests (false-belief tasks, strange stories, intentionality/memory questions) and a set of "modification" (perturbation) tests designed to probe the robustness of ToM reasoning rather than just raw accuracy.

## Overview

The pipeline has three stages:

1. **Prompting** (`main.py`, `src/`) — run a battery of ToM questions against several LLM APIs (with and without extended/explicit reasoning) and save the raw responses.
2. **Grading** (`scripts/grade_*.py`) — interactive CLI tools for manually scoring each model response against the correct answer.
3. **Analysis** (`analysis.ipynb`) — aggregate graded results into accuracy tables and heatmaps, broken down by task type, ToM order/level, and model.

## Experiments

`main.py` exposes four experiment types (selected interactively):

| Experiment | Data source | What it tests |
|---|---|---|
| **Psychological tests** | `data/queries_treated.csv` | Classic ToM batteries (Sally-Anne false-belief, strange stories, intentionality/memory questions) with the model's full reasoning trace preserved |
| **Psychological tests (no reasoning)** | `data/queries_non_reasoning.csv` | Same battery, but prompted without an explicit reasoning/system framing |
| **Simple Modifications** | `data/modifications.csv` | Perturbed/edge-case ToM scenarios designed to test robustness of correct answers |
| **Modifications (no reasoning)** | `data/modifications_no_reasoning.csv` | Same perturbation set, without the explicit reasoning prompt |

Each experiment writes a per-model CSV of raw outputs (e.g. `psic-results-claude.csv`, `mod-results-r1.csv`) into the working directory, and the checked-in copies live under `results/psic/raw/` and `results/mod/raw/`.

## Models supported

Defined in `main.py` / `src/prompt_models.py`:

- **DeepSeek** — `deepseek-reasoner` (`r1`)
- **OpenAI** — `gpt-5-2025-08-07` at `high` and `minimal` reasoning effort
- **Google** — `gemini-2.5-pro`
- **Anthropic** — `claude-opus-4-1-20250805`, with and without extended thinking
- **xAI** — `grok-4-0709`, `grok-3-mini`

Each wrapper class implements a common `prompt(userPrompt, systemPrompt)` / `reprompt(last, newUserPrompt)` interface so multi-turn follow-up questions can be chained against the same conversation.

## Setup

### Requirements

- Python 3.10+
- API keys for whichever providers you want to query:
  - `openai` (OpenAI + xAI, which uses an OpenAI-compatible endpoint, and DeepSeek, which does too)
  - `google-genai` (Gemini)
  - `anthropic` (Claude)
  - `pandas`, `tqdm`

```bash
pip install openai google-genai anthropic pandas tqdm
```

> **Note:** API keys are currently instantiated as empty strings inside `src/prompt_models.py` (e.g. `OpenAI(api_key="")`). You'll need to either edit those in place or change them to read from environment variables (e.g. `os.environ["OPENAI_API_KEY"]`) before running anything — the clients will not pick up keys automatically otherwise.

### Running an experiment

```bash
python main.py
```

You'll be prompted to select an experiment and a model from numbered lists, e.g.:

```
Select the experiment for the experiment:
  0) Psicological tests
  1) Psicological tests (no reasoning)
  2) Simple Modifications
  3) Modifications (no reasoning)
Enter a number: 0

Select the model for the experiment:
  0) r1
  1) gpt-5-high
  2) gpt-5-minimal
  3) gemini
  4) claude
  5) claude-no-thinking
  6) grok-4
  7) grok-3-mini
Enter a number: 4
```

The script iterates over every row of the relevant CSV, calls the model (retrying on API errors), and writes results out incrementally after each row so progress isn't lost on a crash.

### Grading

Grading is manual and done via terminal prompts. For each response the script clears the screen, prints the question/reasoning/answer alongside the correct answer, and asks for a `0`/`1`/`2` grade:

```bash
python scripts/grade_psi_tests.py results/psic/raw/psic-results-claude.csv results/psic/graded/psic-graded-claude.csv
python scripts/grade_mod_tests.py results/mod/raw/mod-results-claude.csv results/mod/graded/mod-graded-claude.csv
```

Use `grade_psi_no_reas_tests.py` / `grade_mod_no_reas_tests.py` for the no-reasoning-prompt result files. Graded CSVs add a `C` column with the manual correctness score.

### Analysis

`analysis.ipynb` reads every graded CSV in `results/psic/graded/` and `results/mod/graded/`, computes per-task-type and overall accuracy for each model, and renders styled heatmaps (with LaTeX export via pandas Styler) for the paper's tables — covering the Sally-Anne false-belief tasks, strange stories, and intentionality/memory (Hi-ToM style) questions, plus the robustness/modification results.

## Data format

- **Psychological test CSVs** (`queries_treated.csv`, `queries_non_reasoning.csv`): columns include `Type` (task category, e.g. `SA_1fb`, `SS_2pretend`, `H_1`), `S` (system prompt), `Q_1`/`Q_2`(`/Q_3`) (questions), `CA_1`/`CA_2` (correct answers), and `A_*`/`R_*` columns populated by the experiment run (answer / reasoning trace).
- **Modification CSVs** (`modifications.csv`, `modifications_no_reasoning.csv`): columns include an item ID, `Q` (the scenario/question, often a True/False or fill-in-the-blank probe), `CA` (correct answer), and `A`/`R` populated on run.
- **Graded CSVs**: same as above plus a `C` column (`0`, `1`, or `2`) recording the manual grade.
